# Skillaz AI — обучение

Интерактивное desktop-демо: автор курса, тьютор и UX-гид. Все данные вымышленные. Ответы детерминированные; файлы — демонстрационные образцы. Реальных AI/API вызовов нет.

Разместите всё содержимое этой папки на статическом HTTP-сервере или GitHub Pages. Вход — index.html; маршрутизация через hash. Пути относительные, подходит подпуть проекта. Запуск через file:// не поддерживается ES-модулями браузера.

Данные хранятся локально отдельно по ролям и примерам. Сброс доступен в «Состояниях демо». Сброс одного примера не стирает работу другой роли.

UI использует сохранённые материалы Skillgrid и Inter из исходного проекта. Это прототип обсуждаемого UX, не рабочая LMS. Публикация, назначения, серверные права и реальные интеграции не реализованы.
